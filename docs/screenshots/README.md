# App Store Screenshots

Place finalized 6.7" iPhone screenshots here before uploading to App Store Connect.

**Required size:** 1290 × 2796 px (iPhone 15 Pro Max / 14 Pro Max portrait)

## Recommended shots

| # | Screen | How to capture |
|---|--------|----------------|
| 1 | Home — Their World | Pair with partner, fill presence cards |
| 2 | Daily photo + streak | Both partners sent today's photo |
| 3 | Distance map | Open Distance from home |
| 4 | Games | Play tab with game grid |
| 5 | Memories | Photos → memories list |
| 6 | Widget (optional) | Add Orbit widget to home screen, screenshot |

## Capture on Simulator

```bash
cd frontend
npx expo run:ios
# Simulator → I/O → Device → iPhone 15 Pro Max
# Navigate to screen → File → Save Screen (⌘S)
# Save into this folder as 01-home.png, 02-daily-photo.png, etc.
```

## Capture on device

Volume Up + Side button, then AirDrop to Mac and resize if needed.

## Optional framing

Use [Apple Design Resources](https://developer.apple.com/design/resources/) or [screenshots.pro](https://screenshots.pro) to add device bezels and captions.
